# Implement a simple web application using Express.js to demonstrate Error Handling, Static Resources and Rate-Limiting Mechanisms

## Execution steps

node app.js

## Outputs

http://localhost:3000/  
Displays index.html with CSS and image.

http://localhost:3000/hello  
Displays: Hello Express.js

Invalid URL  
Displays: Page Not Found

After 5 requests in one minute  
Displays: Too many requests, please try again later.

## Result

Successfully demonstrated static resources, error handling and rate limiting in Express.js.
